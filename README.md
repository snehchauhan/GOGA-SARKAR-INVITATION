## Music

Place your devotional MP3 at:

`assets/music.mp3`

The site will still work if the MP3 is missing; the music control is hidden automatically.

## Run locally

Open `index.html` directly in a browser, or use VS Code's Live Server extension.

## Free GitHub Pages deployment

1. Create a new GitHub repository.
2. Upload the files and the `assets` folder while preserving the folder structure.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. GitHub will provide your live website URL after deployment.

## Google Maps

The GET DIRECTIONS button searches Google Maps for `DKM Hospital`. If there are multiple hospitals with that name, replace the URL in `index.html` with the exact Google Maps place URL for your venue.
